# Jetson BSP Report

Use this skill when creating Jetson/MIC BSP factory verification PPT reports from terminal commands and output evidence.

## Scope

This skill creates USB3 verification report pages from a lightweight white template:

- Template: `assets/blank_logo_template.pptx`
- Slide 22: USB3 packet size verification, one evidence image.
- Slide 23: USB block device verification, six evidence images.
- The Advantech logo in the template comes from `assets/logo-1.png` and is already placed in the lower-right corner.
- Evidence images are generated by script from terminal output.

Do not generate logos or paste full reference page screenshots into the PPT. Use the blank logo template and add report content with code.

## Workflow

1. Generate or collect terminal output.
   - For slide 22, collect one transcript containing all six packet size commands and outputs.
   - For slide 23, execute all six block-device commands and save each command result as JSON.
   - Demo modes are only for layout testing. Do not use demo output as a real verification result.
2. Render the transcript into a terminal-style PNG.
   - Use black background, green prompt, blue path, gray command text, red output values, and a red highlight box around matched output values.
   - For slide 23, highlight only actual `block/sdX` tokens. If a command does not output `block/sdX`, render the real output without adding fake success text.
3. Create the PowerPoint report page.
   - Use `scripts/create_single_slide_report.py`.
   - With only `--screenshot`, it creates a one-slide slide 22 report.
   - With `--block-screenshots`, it creates a two-slide report from the blank logo template and inserts six generated block-device evidence images.
4. Validate the result.
   - Confirm the PPTX has the expected slide count.
   - Confirm all screenshot images are newly generated terminal evidence.
   - Confirm the logo remains from `assets/blank_logo_template.pptx`.

## Commands

From the skill directory:

```bash
python3 scripts/render_terminal_png.py \
  --demo usb3 \
  --output /absolute/path/to/terminal_usb3.png
```

Render six slide 23 block-device images from real command results:

```bash
python3 scripts/render_terminal_png.py \
  --results-json /absolute/path/to/usb3_block_results.json \
  --output-dir /absolute/path/to/block_images \
  --prefix usb3_block \
  --highlight-regex 'block/sd[a-z]+' \
  --highlight-mode token \
  --width 1300 \
  --font-size 18
```

Create a two-page report:

```bash
python3 scripts/create_single_slide_report.py \
  --template assets/blank_logo_template.pptx \
  --screenshot /absolute/path/to/terminal_usb3.png \
  --block-screenshots \
    /absolute/path/to/block_images/usb3_block_1.png \
    /absolute/path/to/block_images/usb3_block_2.png \
    /absolute/path/to/block_images/usb3_block_3.png \
    /absolute/path/to/block_images/usb3_block_4.png \
    /absolute/path/to/block_images/usb3_block_5.png \
    /absolute/path/to/block_images/usb3_block_6.png \
  --output /absolute/path/to/usb3_factory_verification_two_pages.pptx
```

Create the original one-page report:

```bash
python3 scripts/create_single_slide_report.py \
  --template assets/blank_logo_template.pptx \
  --screenshot /absolute/path/to/terminal_usb3.png \
  --output /absolute/path/to/usb3_factory_verification.pptx
```

## Real Transcript Format

For real command output, store text like:

```text
mic-741@ubuntu:/$ sudo cat /sys/bus/usb/devices/2-3.1/bMaxPacketSize0 | grep 9
9
mic-741@ubuntu:/$ sudo cat /sys/bus/usb/devices/2-3.2/bMaxPacketSize0 | grep 9
9
```

Then run:

```bash
python3 scripts/render_terminal_png.py \
  --input /absolute/path/to/transcript.txt \
  --output /absolute/path/to/terminal.png \
  --highlight-regex '^9$'
```

## Slide 23 Command Result JSON

For slide 23, store a JSON list of six command results. Keep failed command output as-is; do not invent a `block/sdX` path.

```json
[
  {
    "prompt": "mic-741@ubuntu:/$",
    "command": "sudo find /sys/bus/usb/devices/2-3.1/ | grep block/sd.$",
    "stdout": "/sys/bus/usb/devices/2-3.1/2-3.1:1.0/host0/target0:0:0/0:0:0:0/block/sda",
    "stderr": "",
    "exit_code": 0
  },
  {
    "prompt": "mic-741@ubuntu:/$",
    "command": "sudo find /sys/bus/usb/devices/2-3.2/ | grep block/sd.$",
    "stdout": "",
    "stderr": "",
    "exit_code": 1
  }
]
```

## Output Rules

- Keep all generated files outside the skill directory unless explicitly updating skill assets.
- Use absolute paths for output files.
- Use `assets/blank_logo_template.pptx` as the report base.
- If real output does not satisfy the pass rule, still render the evidence image, but report the page as failed or needing review in the final response.
